# Waste Image Assets Directory
Place any sample waste item images (.jpg, .jpeg, .png, .webp) in this directory for testing.

Supported test categories & examples:
1. Organic (e.g., banana_peel.jpg, tomato.jpg, potato.png)
2. Recyclable (e.g., plastic_bottle.jpg, cardboard.png, can.jpg)
3. Non-Recyclable (e.g., wrapper.jpg, dirty_plastic.png, mixed_waste.jpg)
4. Hazardous (e.g., battery.jpg, e_waste.png, chemical_bottle.jpg)
