The Three Waste Categories

Trained taxonomy for autonomous smart bin segregation.

ORGANIC BIN

Organic

Biodegradable food scraps, kitchen waste, and organic materials suitable for composting.

Examples: Tomato, Potato, Banana, Banana peel, Fruit scraps, Vegetable waste, Leftover food.
REUSABLE BIN

Reusable

Dry, clean materials that can be remanufactured into new products and packaging.

Examples: Plastic water bottles, Soda cans, Clean cardboard, Paper, Tin containers, Metal cans.
INORGANIC BIN

Inorganic

Non-recyclable, hazardous, and residual waste requiring appropriate handling.

Examples: Dirty wrappers, batteries, electronic waste, oily boxes, polystyrene, mixed waste.

Camera Troubleshooting Guide

If the webcam fails to open, verify these 6 critical checks:

1

Browser Permissions

Click the lock 🔒 icon in Chrome's address bar → Site settings → Set Camera to Allow.

2

Windows Privacy

Open Windows Settings → Privacy & Security → Camera → Enable Let desktop apps access your camera.

3

Close Conflicting Apps

Ensure Microsoft Teams, Zoom, Skype, Google Meet, or Windows Camera app are fully closed.

4

Refresh the Page

Press Ctrl + F5 to clear cached media stream handles and re-prompt device selection.

5

Device Selection

If using an external USB webcam, ensure it is selected as default in Chrome media settings.

6

Run on Localhost / Live Server

Browsers restrict camera access on file:// URLs. Always serve via VS Code Live Server (http://localhost:5500).
